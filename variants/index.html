Letter Flower

Seven versions of the same game to try side by side. Tap one to play; use the browser's back button to return here.

  • F. Hybrid (your pick) The tidy top of A (level name, recent words, the word you are spelling, menu) over the big flower and big buttons of B. f-hybrid.html
  • Core (baseline) The original layout with the Android tap fixes and named levels. Compare the others against this. core.html
  • A. Tidy Least change: today's layout squeezed onto one screen, word lists moved into the menu. a-tidy.html
  • B. Big Flower The flower fills the screen for the biggest letters, with big icon buttons at the bottom. b-bigflower.html
  • C. Pot & Petals Progress is a picture: a plant that grows, with found words dropping into its pot. Very little text. c-pot.html
  • D. Tap Tiles The word is a row of tiles; tap any tile to take that letter out. No Back button. d-tiles.html
  • E. Garden Path A strip of level flowers on the main screen to hop between levels, with big Peek and Hear hints. e-garden.html
Progress is shared. All seven versions save to the same place in this browser (the same lf2- save keys), because they are opened from the same folder. Words found in one version show as found in the others, and they all resume at the same level. To compare from a fresh start, reset progress before opening the next one.
